Group Theory From Actions concept / 概念

Generator / 生成元

An element whose repeated action visits the whole cyclic group; in \(\mathbb Z_n\) it is a step \(g\) with \(\gcd(n,g)=1\). 反复作用后能走遍整个循环群的元素；在 \(\mathbb Z_n\) 中它对应满足 \(\gcd(n,g)=1\) 的步长 \(g\)。

Definition / 定义

An element whose repeated action visits the whole cyclic group; in \(\mathbb Z_n\) it is a step \(g\) with \(\gcd(n,g)=1\).

反复作用后能走遍整个循环群的元素；在 \(\mathbb Z_n\) 中它对应满足 \(\gcd(n,g)=1\) 的步长 \(g\)。

\[\langle g\rangle=\mathbb Z_n\quad\Longleftrightarrow\quad \gcd(n,g)=1\]
