Large Language Models: Tokens, Context, Sampling Concept Tree / 概念树

The LLM project explains language models as token processors, context readers, probabilistic samplers, and grounded tool users. LLM 项目把大语言模型解释为 token 处理器、上下文阅读器、概率采样器和依托资料/工具的协作者。

1

Token / token

Definition: The basic text unit an LLM processes: a character, word, word piece, number, or punctuation mark.

定义：模型处理文本的基本单位，可能是字、词、词片段、数字或标点。

\[x_{1:n}=(x_1,x_2,\ldots,x_n)\]

Upstream: Chapter 0 intuition. Downstream: Context window.

2

Context window / 上下文窗口

Definition: The range of tokens the model can directly read now, including instructions, history, documents, and tool results.

定义：模型当前能直接读取的 token 范围，包含指令、问题、历史、资料和工具结果。

\[x_{t-L+1:t}\]

Upstream: Token. Downstream: Temperature.

3

Temperature / 温度

Definition: A sampling parameter that shapes the probability distribution; lower is steadier, higher is more diverse.

定义：采样时调节概率分布形状的参数；低温更稳定，高温更发散。

\[p_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}\]

Upstream: Context window. Downstream: Grounding.

4

Grounding / 扎实度

Definition: How much an answer rests on current context, documents, or tool outputs instead of parameter memory alone.

定义：回答是否依托当前上下文、资料或工具结果，而不是只依赖模型参数记忆。

\[G=\frac{\text{supported claims}}{\text{all claims}}\]

Upstream: Temperature. Downstream: takeaway and review.
