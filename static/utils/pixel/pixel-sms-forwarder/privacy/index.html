Pixel SMS Forwarder

Privacy Policy

Effective date: September 25, 2026

Purpose and scope

Pixel SMS Forwarder is a personal Android utility and default SMS handler. At the user's direction, it receives ordinary SMS messages, stores them in Android's system SMS database, and forwards newly received messages as email through the user's Google Account. This policy describes the current Android build.

Data the app handles

  • SMS data: sender or recipient address, message body, and message time. Newly arriving SMS messages are stored locally and queued for forwarding. Existing SMS messages may be read from Android's system SMS database only to display them in the app's local SMS view; they are not added to the forwarding queue.
  • Default-handler access: Android grants the app SMS receive, read, and send privileges while the user keeps it selected as the default SMS application.
  • Google Account data: the user-selected account's primary email address, stored locally so background sending remains pinned to that account and used to construct the From header.
  • Gmail access: permission to send an email on the user's behalf.
  • Operational data: a local queue identifier, retry state, and last successful send time.

Google API scopes and use

  • gmail.send is used only to send the user-requested SMS forwarding email.
  • userinfo.email is used only to obtain the sending account's primary email address.

The app does not request permission to read, modify, or delete Gmail messages. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

As the default SMS handler, the app writes received and sent SMS messages to Android's system SMS database. Separately, if a newly received message cannot be emailed immediately, its sender and body are stored in an on-device queue encrypted with AES-256-GCM using a key held by Android Keystore. The queued copy is deleted after Gmail confirms a successful send. Turning forwarding off clears the unsent forwarding queue but does not delete messages from Android's system SMS database. App data is excluded from cloud backup and device transfer.

OAuth credentials are managed by Google Play services. The app does not write access tokens to its own database or logs. Copies already sent remain subject to the retention controls of Gmail and the destination mailbox.

Sharing and transfers

The app sends data directly from the device to Google's Gmail API so Gmail can deliver the forwarding email to the destination mailbox configured in the app (currently chenzhao.sg@gmail.com). The developer operates no intermediary server and does not sell, rent, or use the data for advertising or analytics.

User control

The user can select or replace the sending Google Account, stop forwarding and clear the unsent local queue from the app. The user can replace Pixel SMS Forwarder with another default SMS application at any time in Android settings, which removes role-based SMS privileges. Android notification permission can also be revoked in system settings. Google Account access can be revoked from the Google Account's third-party access settings.

Security

The app uses HTTPS for Google API traffic, disallows cleartext network traffic, encrypts queued SMS content on the device, and avoids logging SMS content or access tokens. No security measure can eliminate every risk, particularly when SMS messages contain sensitive or one-time authentication information.

Changes and contact

This policy will be updated when the app's data practices change. For privacy or support questions, use the support contact shown on the Google OAuth consent screen.
