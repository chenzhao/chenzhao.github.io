Color Modules / 七大模块

Optics, color theory, sensors, image formats/compression, and HDR now have first content drafts. Graphics and vision remain architecture boundaries. 光学、颜色、传感器、图像压缩、HDR 已填入第一版内容；图形学和视觉仍是骨架。

01 Optics / 最基础的光学

Content draft: radiometry, lenses, pupils, diffraction, PSF/MTF, aberrations, and imaging system design.

02 Color Theory / 颜色理论

Content draft: spectra, XYZ, RGB spaces, linear light, Lab, adaptation, appearance, and color management.

03 Sensors / 传感器原理

Content draft: pixel physics, noise, CMOS readout, shutter, sensor HDR, CFA, SPAD, ToF, QIS, and event cameras.

04 Formats & Compression / 图像格式和压缩

Content draft: DCT mathematics, JPEG 8×8 block coding, quantization, entropy coding, PNG, WebP, HEIC/HEIF, and format selection.

05 HDR / HDR 专题

Content draft: dynamic range, PQ/HLG, HDR formats, tone mapping, mastering, display, delivery, and QC.

06 Graphics / 计算机图形学

Rendering, materials, lighting, cameras.

07 Vision / 计算机视觉

Image formation, features, geometry, recognition.
