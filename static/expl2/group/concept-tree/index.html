Group Theory From Actions Concept Tree / 概念树

The group project explains groups through modular addition, cyclic generation, square symmetries, and cosets. 群论项目通过模加法、循环生成、正方形对称和陪集解释群。

1

Group / 群

Definition: A set with an operation \((G,*)\) satisfying closure, associativity, identity, and inverses.

定义：一个集合加上一种运算 \((G,*)\)，并满足封闭性、结合律、单位元和逆元四条规则。

\[(a*b)*c=a*(b*c),\qquad e*a=a*e=a\]

Upstream: Chapter 0 intuition. Downstream: Generator.

2

Generator / 生成元

Definition: An element whose repeated action visits the whole cyclic group; in \(\mathbb Z_n\) it is a step \(g\) with \(\gcd(n,g)=1\).

定义：反复作用后能走遍整个循环群的元素；在 \(\mathbb Z_n\) 中它对应满足 \(\gcd(n,g)=1\) 的步长 \(g\)。

\[\langle g\rangle=\mathbb Z_n\quad\Longleftrightarrow\quad \gcd(n,g)=1\]

Upstream: Group. Downstream: Symmetry.

3

Symmetry / 对称

Definition: An action that preserves an object's structure; the square symmetries form \(D_4\).

定义：保持对象结构不变的动作；正方形的对称动作组成 \(D_4\)。

\[r^4=e,\qquad s^2=e,\qquad srs=r^{-1}\]

Upstream: Generator. Downstream: Coset.

4

Coset / 陪集

Definition: A shifted copy of a subgroup, written \(aH=\{ah:h\in H\}\); finite groups are partitioned into equal-size cosets.

定义：把一个子群整体平移得到的集合，写作 \(aH=\{ah:h\in H\}\)；有限群会被同样大小的陪集整齐分割。

\[aH=\{ah:h\in H\},\qquad |G|=[G:H]|H|\]

Upstream: Symmetry. Downstream: takeaway and review.
