PQ / HLG

PQ 是绝对显示亮度系统，HLG 是更适合广播兼容的相对系统。

格式生态

HDR10、HLG、Dolby Vision、HDR10+、HDR Vivid 各有 metadata 和适配策略。

Tone mapping

高光 roll-off、暗部保留、肤色稳定、色域压缩和时域一致性必须一起考虑。

交付接口

bit depth、YCbCr/ICtCp、chroma subsampling、transfer、primaries 和 metadata 缺一不可。
