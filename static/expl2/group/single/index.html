Chapter 0 / 第 0 章

Intuition first / 先看直觉

The group project explains groups through modular addition, cyclic generation, square symmetries, and cosets.

群论项目通过模加法、循环生成、正方形对称和陪集解释群。

Concept 1 / 概念 1

Group / 群

A set with an operation \((G,*)\) satisfying closure, associativity \((a*b)*c=a*(b*c)\), identity \(e*a=a*e=a\), and inverses \(a*a^{-1}=a^{-1}*a=e\).

一个集合加上一种运算 \((G,*)\)，并满足封闭性、结合律 \((a*b)*c=a*(b*c)\)、单位元 \(e*a=a*e=a\) 和逆元 \(a*a^{-1}=a^{-1}*a=e\) 四条规则。

Example / 例子

modular-addition Cayley table shows the concept in operation. 模加法 Cayley 表展示这个概念如何运作。

Concept 2 / 概念 2

Generator / 生成元

An element whose repeated action visits the whole cyclic group; in \(\mathbb Z_n\) it is a step \(g\) with \(\gcd(n,g)=1\).

反复作用后能走遍整个循环群的元素；在 \(\mathbb Z_n\) 中它对应满足 \(\gcd(n,g)=1\) 的步长 \(g\)。

Example / 例子

cyclic orbit view shows the concept in operation. 循环轨道视图展示这个概念如何运作。

Concept 3 / 概念 3

Symmetry / 对称

An action that preserves an object's structure, such as rotating or reflecting a square; the square symmetries form \(D_4\) with \(r^4=e,\ s^2=e,\ srs=r^{-1}\).

保持对象结构不变的动作，例如正方形的旋转和翻转；这些动作组成二面体群 \(D_4\)，满足 \(r^4=e,\ s^2=e,\ srs=r^{-1}\)。

Example / 例子

square-corner position diagram shows the concept in operation. 正方形角点位置图展示这个概念如何运作。

Concept 4 / 概念 4

Coset / 陪集

A shifted copy of a subgroup, written \(aH=\{ah:h\in H\}\); finite groups are partitioned into equal-size cosets with \(|G|=[G:H]|H|\).

把一个子群整体平移得到的集合，写作 \(aH=\{ah:h\in H\}\)；有限群会被同样大小的陪集整齐分割，并满足 \(|G|=[G:H]|H|\)。

Example / 例子

subgroup and coset rows shows the concept in operation. 子群与陪集行展示这个概念如何运作。
