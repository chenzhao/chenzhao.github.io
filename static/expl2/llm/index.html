4. Embeddings / 向量表示

词不是表格编号，而是空间位置 / Tokens become positions in a space

Embedding 把 token 变成向量，让相似用法能在空间里靠近。Embeddings turn tokens into vectors so related uses can sit near each other.

Details / 详细

模型不能直接计算“意义”，但它可以学习许多维度上的数值表示。两个词如果常在相似语境中出现，它们的向量会倾向于更接近；这给后续注意力和预测提供了可计算材料。

The model cannot calculate meaning directly, but it can learn numerical representations across many dimensions. Tokens with similar contexts tend to land closer together, giving attention and prediction something computable to use.

Vector sketch
\[e_i=E[x_i]\in\mathbb R^d,\qquad \operatorname{sim}(e_i,e_j)=\frac{e_i\cdot e_j}{\lVert e_i\rVert\lVert e_j\rVert}\]

5. Attention / 注意力

每一步都重新读取上下文 / Each step rereads the context

注意力让当前 token 从上下文里取回相关信息，而不是只看最后一个词。Attention lets a token retrieve relevant context, not just the previous word.

Details / 详细

生成下一个 token 时，模型会计算上下文中哪些位置更相关。代词、变量名、格式约束和引用资料都可能被注意力重新连接，这就是长距离依赖能被处理的原因。

When generating the next token, the model scores which earlier positions matter. Pronouns, variable names, formatting constraints, and retrieved documents can all be reconnected through attention.

Attention path
\[\alpha_{ij}=\operatorname{softmax}_j\left(\frac{q_i k_j^\top}{\sqrt d}\right),\qquad y_i=\sum_j \alpha_{ij}v_j\]

6. Pretraining / 预训练

能力来自大量预测练习 / Capability comes from prediction practice

预训练让模型在大量文本上练习预测，从而压缩语言模式、事实片段和推理套路。Pretraining compresses patterns by practicing prediction at scale.

Details / 详细

模型不是逐条保存网页，而是在参数里形成统计结构。它能把模式迁移到新任务，但也会把相似模式误用到不该用的地方；这解释了能力和幻觉为什么同时出现。

The model does not store pages line by line; it forms statistical structure in parameters. That structure transfers to new tasks, but it can also apply a plausible pattern where it does not belong.

7. Alignment / 对齐

会续写还不等于会当助手 / Continuation is not yet assistance

对齐训练把会续写的模型塑造成更会遵循指令、承认限制和拒绝危险请求的助手。Alignment shapes a continuation model into an assistant.

Details / 详细

预训练提供语言能力，对齐改变行为偏好。它让模型更愿意按要求组织答案，但不会凭空创造事实；如果证据缺失，仍需要上下文、检索或工具补足。

Pretraining supplies language ability; alignment changes behavioral preferences. It improves instruction following, but it does not create missing facts, so context and tools remain necessary.

Behavior layer
\[\theta'=\arg\max_\theta \mathbb E_{y\sim p_\theta(\cdot\mid x)}[r_\phi(x,y)]\]

8. Evaluation / 评估

好回答必须能被检查 / A good answer can be checked

评估不只看流畅度，还要看事实、推理、格式、边界和可复现证据。Evaluation asks whether the answer is correct, bounded, and checkable.

Details / 详细

LLM 的输出很容易显得自信，所以评估要把问题拆开：依据在哪里，计算能否复现，引用是否支持结论，格式是否满足约束。可靠使用模型，本质上是在设计更好的检查流程。

LLM output can sound confident, so evaluation separates evidence, reproducible calculation, source support, and format constraints. Reliable use is largely a matter of designing better checks.

Check stack
\[\mathrm{score}=F(\mathrm{facts},\mathrm{reasoning},\mathrm{format},\mathrm{sources})\]
