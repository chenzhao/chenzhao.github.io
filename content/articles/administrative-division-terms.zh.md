“省、州、县、郡”看起来像一套固定的等级表，其实不是。同一个字在不同朝代、不同国家，可能指完全不同的层级。行政区划名称既记录制度，也保存历史；翻译它们时，最危险的办法就是只找一个看起来相像的汉字。

本文只做一张简明地图：集中说明历史上反复使用、并且今天仍影响语言的主要名称。历代还有大量短期、边疆和地方性称号，不可能在一篇短文中穷尽。

## 一、中国：字没变，层级一直在变

| 名称 | 大致的历史变化 |
| --- | --- |
| **州** | 《禹贡》的“九州”首先是天下地理观念。汉代州逐渐成为监察区域，东汉后转成实际行政层级；隋唐以后又在不同阶段处于郡县之间或与郡互换。今天中国大陆的“自治州”是省级以下的民族自治地方，并不是美国 `state` 那种联邦成员。 |
| **郡、县** | 县出现很早，战国时郡县并行，秦统一后形成郡辖县的两级制。汉代郡与国同级。隋以后“郡”多次被改称为州，最终退出中国大陆常规区划；“县”却延续至今。也就是说，县比许多听起来更古老、更宏大的名称更稳定。 |
| **道** | 汉代可用于少数民族地区的县级单位；唐代的道主要从监察区发展而来，后来行政色彩增强；明清又有作为派出官员辖区的“道”。民国初年曾在省与县之间恢复道，后来废除。 |
| **路** | 宋代的路起初偏重财政、转运和军事事务，逐渐成为高层区划；元代行省之下仍设路。今天“路”主要是道路名称，不再是中国大陆行政层级。 |
| **府、厅** | 唐代常把都城、陪都或重要州升为府；明清的府通常辖州县。清代的厅多见于边疆或新开发地区，有直隶厅、散厅等不同地位。民国初年府、州、厅大体被废。 |
| **省** | “省”原来首先是官署名称。元代的行中书省使它逐渐成为大区名称，明清以后稳定为最高层地方区划之一。它不是从古至今都表示同一级。 |
| **市、区** | 这是近代城市化和现代地方政府制度的产物。今天“市”可能是直辖市、地级市或县级市，单看“市”字不能判断层级；“区”也可能是市辖区、特别行政区或其他功能区。 |
| **乡、镇、街道** | 乡在先秦已经出现，后世含义和规模多变；镇最初常与军事驻防、市场聚落有关，后来成为基层行政单位。现代大陆通常把乡、镇、街道放在相近的基层治理层次。 |
| **村、里、保、甲** | 这些词长期用于基层编组、户籍和治安，但未必都是正式行政层级。今天大陆的村民委员会、居民委员会是基层群众性自治组织；宪法把乡、民族乡、镇列为行政区划，却把村居组织另列规定。 |
| **盟、旗、苏木** | 这些名称来自蒙古地区的历史制度，今天仍用于内蒙古。国家行政区划代码规则分别把盟按地区、旗按县、苏木按乡处理，说明“同级”并不要求“同名”。 |

现行中国大陆的基本层级可由《宪法》第三十条概括为省级、县级、乡级，但实际名称比三层丰富得多；村和社区则不能简单算作“第四级行政区”。可参见[全国人大公布的《中华人民共和国宪法》第三十条、第一百一十一条](https://www.npc.gov.cn/npc/c1773/c1848/c21114/c33714/c33717/201905/t20190521_206995.html)以及[司法部关于行政区划代码的规则](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202512/t20251204_528920.html)。州、郡、县的历史更替可参考[郑州市民政局地名文化资料](https://mzj.zhengzhou.gov.cn/work/8540150.jhtml)；路、府、省等制度沿革可参见[陕西省地方志办公室资料](https://dfz.shaanxi.gov.cn/zslm/fzzlk/sxjz/xys_16200/201706/P020240923597331777089.pdf)。

## 二、汉字文化圈：借了同一个字，没有借同一套等级

### 日本

日本今天的普通地方公共团体分为“都道府县”和“市町村”两层：东京为都，北海道为道，大阪、京都为府，其余为县；基层则有市、町、村。日本《地方自治法》明确把都道府县和市町村并列为普通地方公共团体。这里的“县”是最高层地方单位之一，与中国大陆的县完全不同。“郡”今天主要是町、村所在地区的地理名称，不是一级自治政府。参见日本政府[e-Gov《地方自治法》第一条之三、第二条](https://laws.e-gov.go.jp/law/322AC0000000067)。

### 韩国

韩国仍广泛使用汉字词的韩语读音：道（도）、市（시）、郡（군）、区（구）、邑（읍）、面（면）、洞（동）、里（리）。大体上，道与特别市、广域市等构成高层单位，市、郡、区在下一层，邑、面、洞以及里用于更基层。韩国行政安全部列出的高层地方政府名称仍包括京畿道、江原道等；韩国中央选举管理委员会也按“市/道—区/市/郡—邑/面/洞”说明其组织层级。参见[韩国行政安全部](https://www.mois.go.kr/eng/sub/a03/citiesProvinces/screen.do)和[韩国中央选举管理委员会](https://www.nec.go.kr/site/eng/01/10103000000002020070611.jsp)。

### 越南

越南语中也保留大量汉越词。常见写法包括省（tỉnh）、县（huyện）、郡（quận）、市社（thị xã）、社（xã）、坊（phường）、市镇（thị trấn）。现代越南制度中，省和中央直辖市在高层；县、郡、市社等在中层；社、坊、市镇在基层。“郡”在这里通常是城市内部单位，“县”多用于非都市地区，和古代中国的郡县关系已经不同。越南政府关于设立城市、省属市、市社、郡、坊、市镇的法规可见[越南政府法律数据库](https://vanban.chinhphu.vn/default.aspx?docid=101902&pageid=27160)。

### 台湾

台湾现行用语包括直辖市、县、市、区、乡、镇、县辖市、村、里、邻。“县”仍是重要地方自治单位；县以下可设乡、镇、县辖市，直辖市下设区。这里的县与日本最高层的县不同，也与美国 county 不能机械对号。台湾地区领导人办公室对《地方制度法》的英文介绍概括了这套层级，可参见[Local governments](https://english.president.gov.tw/Page/106)。

## 三、翻译：`state` 应该是“邦”吗？

我的倾向是：**在解释美国宪制时，`state` 译成“邦”比“州”更能显示它是联邦的成员政治体；但在地名和一般行文中，“州”仍是已经固定的通行译名。**

“州”在现代汉语里容易让人联想到普通行政区，而美国各 state 有自己的宪法、议会、行政和司法制度。写“邦”能提醒读者：它不是中央政府随意划出的省。但“加利福尼亚州”“纽约州”已经是稳定专名，全部改成“邦”会增加阅读成本。因此可以分场合：专名沿用“州”，比较宪制时写“成员邦（state）”。美国人口普查局把 state 定义为美国的首要法定分区，原文可见[Geographies](https://www.census.gov/data/data-tools/survey-explorer/geo.html)。

还有一个容易混淆的拼写：

- `country` 是“国家”，在另一种语境里也可指“乡村”。
- `county` 才是美国 state 之下常见的地方单位。

那么 `county` 应译“郡”还是“县”？**“郡”在字面上能避免和中国的县直接等同，也保留英美历史感；“县”则是现代中文最成熟、最容易识别的惯例。** 更重要的是，美国 county 并非全国完全一致的一级政府：其权限因 state 而异；路易斯安那称 parish，阿拉斯加使用 borough 等单位，有些独立市还被统计为 county equivalent。美国人口普查局对此有明确说明，见[Geographic Terms and Definitions](https://www.census.gov/programs-surveys/popest/about/glossary/geo-terms.html)。

所以我的暂定规则是：

1. 美国地名中的 `state` 沿用“州”，制度分析中可译“邦”或“成员邦”。
2. `county` 在一般地名中沿用“县”；讨论制度比较时第一次出现可写“县（county，亦常译郡）”。
3. 不根据上下级关系强行一一对应，而要说明它有没有自治权、由谁设立、承担什么职能。

行政区划翻译不是把一棵树的标签贴到另一棵树上。真正需要翻译的，是每个单位在整套制度里的位置。
