Concept / 概念

Private Language / 私人语言

A fully private language would fix meanings only by private inner experience. 完全私人语言只靠私人内在经验固定意义。

Definition / 定义

Wittgenstein argues that such a language lacks criteria for correct and incorrect use.

维特根斯坦认为，这种语言缺少区分正确与错误使用的标准。

Example / 例子

If I mark a sensation "S" only by inwardly attending to it, later uses cannot be checked against anything beyond seeming right to me.

如果我只通过内在注意把某种感觉标成“S”，以后使用时就只能靠“我觉得对”来检查。

Dependencies / 依赖

Upstream: meaning as use. Downstream: rule-following and public criteria.

上游：意义即使用。下游：遵守规则与公共标准。
