NP

NP 中每个“是”的答案都有短证据，可在多项式时间内验证。In NP, every yes answer has a short certificate verifiable in polynomial time.

\[x\in L\iff \exists y,\ |y|\le |x|^c\land V(x,y)=1\]

例子 / Example

子集和中，如果有人给出被选数字，验证器只需求和并比较目标。

In subset sum, if someone gives the chosen numbers, a verifier only adds them and compares the target.

关系 / Relations
