可判定 / Decidable

存在一套算法，能对所有合法输入停下来并给出正确的是/否答案。A problem is decidable when an algorithm halts and answers correctly for every valid input.

\[\forall x,\ A(x)\downarrow\ \text{and decides whether}\ x\in L\]

例子 / Example

最短路径判定版可以问“是否存在长度不超过 K 的路径”，这类问题有明确算法。停机问题则不可判定。

The decision version of shortest path asks whether a path of length at most K exists. It has algorithms. The halting problem is undecidable.

关系 / Relations

前置：计算问题。后继：P 与 NP。Upstream: computational problem. Downstream: P and NP.
