Concept index / 概念索引

颜色理论核心概念

颜色科学的危险点通常不是公式复杂，而是变量所在的颜色空间没有说清楚。

SPD

光谱功率分布

物理光源或反射光随波长分布的功率，是颜色计算的输入。

Metamerism

同色异谱

不同光谱在某观察者和照明条件下产生相同三刺激值。

XYZ

CIE XYZ

用标准观察者颜色匹配函数对光谱积分得到的设备无关三刺激。

xyY

xyY

\(x=X/(X+Y+Z)\)，\(y=Y/(X+Y+Z)\)。xy 是色度，Y 是亮度。

White

白点

D65、D50、A 等白点定义中性参考。CCT 相同不代表白点完全相同。

RGB

RGB primaries

RGB 空间由三基色 chromaticity、白点和 transfer function 共同定义。

Transfer

Transfer function

描述线性光与编码值或显示光之间的关系。sRGB、PQ、HLG 都不是线性亮度。

Linear

Scene-linear

与场景光成正比的数值，可用于曝光、合成、能量计算和物理渲染。

Lab

CIELAB

近似感知均匀空间，依赖参考白点，常用于色差评价。

ΔE

色差

CIE76 写作 \(\Delta E^*_{ab}\)，CIEDE2000 更适合工业评价。

CAT

色适应变换

Bradford、CAT02、CAT16 等把源白点下的颜色变换到目标白点下。

ICC

ICC profile

描述设备颜色行为；conversion 保持颜色，assignment 只改变解释。

ACES

ACES / OCIO

影视/VFX 常用的 scene-linear、设备无关色彩管理框架。

Gamut

色域映射

源色域超过目标色域时，需要在裁剪、压缩、色相保持和感知关系之间权衡。
