Concept tree / 概念树

Boltzmannia

This tree shows how the core ideas depend on each other: intuition first, then temperature and entropy, then energy landscapes, and finally Boltzmann machines. 这张树说明核心概念怎样互相依赖：先有直觉图像，再到温度与熵，再到能量景观，最后进入玻尔兹曼机。

0 Intuitive landscape / 直觉地形

A ball prefers valleys but heat can still push it uphill. 小球偏向低谷，但热扰动仍能把它推上高处。

1 Temperature / 温度

Controls how strongly energy differences affect probability. 控制能量差如何影响概率。

2 Entropy / 熵

Counts how many microstates realize the same macrostate. 计数同一宏观状态背后的微观实现方式。

3 Energy landscape / 能量景观

Turns all states into terrain where valleys are more probable. 把所有状态画成地形，低谷更常出现。

4 Boltzmann machine / 玻尔兹曼机

Uses a learned energy landscape to sample data-like states. 用可学习的能量景观抽样数据式状态。

Concept / 概念

Temperature / 温度

Definition: Temperature sets the tolerance for high-energy states. 温度表示系统对高能状态的容忍程度。

\[P(E)=Z^{-1}e^{-E/(kT)}\]

Depends on: the Chapter 0 terrain image. Feeds: Boltzmann distribution, sampling randomness, machine temperature.

Concept / 概念

Entropy / 熵

Definition: Entropy measures how many microscopic ways support one macroscopic description. 熵衡量一个宏观描述背后有多少微观方式。

\[S=k\log W\]

Depends on: macrostate and microstate distinction. Feeds: typicality, equilibrium, learning intuition.

Concept / 概念

Energy landscape / 能量景观

Definition: An energy landscape maps every state to a height; lower height means higher probability. 能量景观把每个状态映射成高度，越低越常出现。

\[p(x)=Z^{-1}e^{-E(x)/T}\]

Depends on: temperature, energy, probability. Feeds: machine state scoring and training.

Concept / 概念

Boltzmann machine / 玻尔兹曼机

Definition: A probabilistic neural model that defines probabilities through an energy function. 玻尔兹曼机是用能量函数定义概率的神经网络模型。

\[P(v,h)=Z^{-1}e^{-E(v,h)/T}\]

Depends on: temperature, entropy, and energy landscape. Feeds: positive phase, negative phase, contrastive learning.
