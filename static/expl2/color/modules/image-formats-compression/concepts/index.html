图像压缩核心概念

本页按 JPEG/DCT 主线组织。每个概念只给定义、公式和用途。

Raw size

原始体积

\(W\times H\times C\times b/8\)。这是压缩前的数据压力。

Redundancy

冗余

图像中可利用的重复和可预测性。包括空间、色彩、感知和统计冗余。

Lossless

无损

解码后 \(x'=x\)。适合文字、截图、二维码和中间资产。

Lossy

有损

允许 \(x'\ne x\)。目标是让失真 \(D(x,x')\) 对用途足够小。

Projection

投影

系数表示数据和某个基函数的重合程度。DCT 系数就是投影结果。

Orthogonal basis

正交基

不同基函数内积为 0。它们互不干扰，系数可以独立解释。

DCT-II

DCT-II

\(X_k=\alpha(k)\sum_n x_n\cos[\pi(n+1/2)k/N]\)。JPEG 使用它的二维版本。

DC

DC 系数

平均项。二维 \(N\times N\) 正交 DCT 中，\(F(0,0)=N\cdot\) 块平均值。

AC

AC 系数

除 DC 外的频率系数。低频 AC 描述缓慢变化。高频 AC 描述快速变化。

Parseval

能量守恒

正交 DCT 满足 \(\sum x_n^2=\sum X_k^2\)。误差也可在系数域计算。

2D DCT

二维 DCT

矩阵形式 \(F=CfC^T\)。先行后列，或先列后行。

Energy compaction

能量集中

平滑图像块的能量常集中在低频。JPEG 利用这个事实。

Level shift

减 128

JPEG 对 8-bit 块先减 128，使数据围绕 0 分布。

Quantization

量化

\(\widehat F=\operatorname{round}(F/Q)\)。这是 JPEG 的主要有损步骤。

Quant table

量化表

每个频率一个步长。低频步长小。高频步长大。

Zigzag

Zigzag 扫描

从低频走向高频。目的是让后半段更容易出现长串 0。

DC diff

DC 差分

JPEG 编码 \(D_i=DC_i-DC_{i-1}\)，因为相邻块平均亮度常相近。

AC RLE

AC 游程编码

非零 AC 用 \((RUN,SIZE)\) 表示。\(RS=16RUN+SIZE\)。

Huffman

Huffman 编码

常见符号用短码。JPEG 默认表常给 EOB、小幅值符号较短码。

EOB

End of Block

若剩余 AC 全为 0，用 EOB 结束，不必继续写 0。

Artifacts

压缩伪影

块效应来自独立分块和强量化。振铃常来自高频被粗略保留或丢弃。

PNG

PNG

行过滤 + DEFLATE。适合无损图形和透明图。

WebP

WebP

lossy 侧强调帧内预测。lossless 侧使用可逆变换和熵编码。

HEIC / HEIF

HEIC / HEIF

HEVC intra coding 加 HEIF 容器。适合现代手机照片和 HDR 元数据。
