Concept / 概念

Meaning as Use / 意义即使用

In many cases, a word's meaning is found in its use in language. 许多情况下，一个词的意义就在它在语言中的使用里。

Definition / 定义

Meaning is not always an object attached to a word; it can be the pattern of correct use, correction, and consequence.

意义不总是贴在词上的对象；它可以是正确使用、纠正和后果的模式。

Example / 例子

"I know" works differently in an exam, a route explanation, and first-person pain expression.

“我知道”在考试、路线说明和第一人称疼痛表达中有不同用法。
