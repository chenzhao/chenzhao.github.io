Personal Android utility

Pixel SMS Forwarder

Pixel SMS Forwarder receives newly arriving ordinary SMS messages on an authorized Android phone and forwards each one as an email using the Gmail API.

The app is designed for personal use on a phone and Google Account controlled by the same user. It does not replace the default SMS app.

What it does

  • Receives new SMS messages after the user grants Android's SMS permission.
  • Uses the minimum Google OAuth scopes needed to identify the sending account and send email.
  • Sends directly from the phone to the Gmail API; the developer operates no relay server.
  • Encrypts an unsent local queue with an Android Keystore key and deletes each queued record after Gmail confirms delivery.

What it does not do

  • It does not read the Gmail inbox, contacts, or previously received SMS messages.
  • It does not process MMS or RCS conversations.
  • It does not sell data, serve advertising, or use analytics.

Terms of use

Use the app only with a device, Google Account, and destination mailbox that you are authorized to control. You are responsible for complying with applicable laws and for protecting any sensitive information contained in forwarded messages. The app is provided as-is for personal use.
