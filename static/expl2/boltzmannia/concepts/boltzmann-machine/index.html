Key concept / 核心概念

Boltzmann machine / 玻尔兹曼机

A Boltzmann machine is a probabilistic neural network that learns which states should become low-energy valleys. 玻尔兹曼机是一种概率神经网络，它学习哪些状态应该成为低能谷。

Definition / 定义

A Boltzmann machine assigns energy to visible and hidden unit configurations. Lower-energy configurations receive higher probability after normalization.

玻尔兹曼机给可见单元和隐藏单元的组合状态分配能量；归一化之后，低能组合得到更高概率。

\[ E(v,h)=-b^\top v-c^\top h-v^\top Wh,\qquad p(v,h)\propto e^{-E(v,h)/T} \]

Example / 例子

With two visible units, the model can favor 00 and 11 if the training data often contains matching pairs. A hidden unit can help represent that association.

若训练数据常出现成对一致的模式，两可见单元模型可以偏向 00 与 11；隐藏单元可以帮助表示这种关联。

Why it matters / 为什么重要

This model connects thermodynamic language to machine learning: data becomes probability, probability comes from energy, and learning reshapes the energy function.

它把热力学语言接到机器学习：数据变成概率，概率来自能量，学习则改造能量函数。
