Large Language Models: Tokens, Context, Sampling concept / 概念

Grounding / 扎实度

How much an answer rests on current context, documents, or tool outputs instead of parameter memory alone; a simple audit score is \(G=\frac{\text{supported claims}}{\text{all claims}}\). 回答是否依托当前上下文、资料或工具结果，而不是只依赖模型参数记忆；一个简化检查分数是 \(G=\frac{\text{有证据支持的断言}}{\text{全部断言}}\)。

Definition / 定义

How much an answer rests on current context, documents, or tool outputs instead of parameter memory alone.

回答是否依托当前上下文、资料或工具结果，而不是只依赖模型参数记忆。

\[G=\frac{\text{supported claims}}{\text{all claims}}\]

Example / 例子

Why it matters / 为什么重要

This concept connects the page's intuition to the later interaction and gives the reader a stable term for review.

这个概念把页面直觉和后续交互连接起来，也给读者一个稳定的复习术语。
