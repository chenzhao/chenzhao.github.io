Core question

传感器是从光子统计到数字码值的转换系统

评价传感器不能只看像素数量。低光、动态范围、运动、色彩、读出速度、热噪声、接口带宽和目标任务共同决定成像质量。

像素物理

QE、BSI、PPD、满井容量和微透镜决定光子能否有效变成电子。

噪声与读出

shot noise、read noise、dark current、CDS、column ADC 决定 raw 的下限。

时序与 HDR

rolling/global shutter、staggered HDR、DCG、LOFIC 和 split pixel 处理运动和高动态。

新型传感器

SPAD、ToF、QIS、event camera 把成像从普通帧扩展到深度、事件和单光子统计。
