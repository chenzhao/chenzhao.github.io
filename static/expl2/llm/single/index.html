Chapter 0 / 第 0 章

Intuition first / 先看直觉

The LLM project explains language models as token processors, context readers, probabilistic samplers, and grounded tool users.

LLM 项目把大语言模型解释为 token 处理器、上下文阅读器、概率采样器和依托资料/工具的协作者。

Concept 1 / 概念 1

Token / token

The basic text unit an LLM processes: a character, word, word piece, number, or punctuation mark; a prompt is a sequence \(x_{1:n}\).

模型处理文本的基本单位，可能是字、词、词片段、数字或标点；提示词可以看成序列 \(x_{1:n}\)。

Example / 例子

token chips and text input shows the concept in operation. token 标记与文本输入展示这个概念如何运作。

Concept 2 / 概念 2

Context window / 上下文窗口

The range \(x_{t-L+1:t}\) of tokens the model can directly read now, including instructions, history, documents, and tool results.

模型当前能直接读取的 token 范围 \(x_{t-L+1:t}\)，包含指令、问题、历史、资料和工具结果。

Example / 例子

visible-window slider shows the concept in operation. 可见窗口滑块展示这个概念如何运作。

Concept 3 / 概念 3

Temperature / 温度

A sampling parameter in \(p_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}\) that shapes the probability distribution; lower is steadier, higher is more diverse.

采样时调节概率分布形状的参数，常写作 \(p_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}\)；低温更稳定，高温更发散。

Example / 例子

candidate probability bars shows the concept in operation. 候选概率条展示这个概念如何运作。

Concept 4 / 概念 4

Grounding / 扎实度

How much an answer rests on current context, documents, or tool outputs; a simple audit score is \(G=\frac{\text{supported claims}}{\text{all claims}}\).

回答是否依托当前上下文、资料或工具结果；一个简化检查分数是 \(G=\frac{\text{有证据支持的断言}}{\text{全部断言}}\)。

Example / 例子

context/tool toggles and score panels shows the concept in operation. 上下文/工具开关与评分面板展示这个概念如何运作。
