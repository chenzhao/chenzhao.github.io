Concept index / 概念索引

传感器核心概念

把 datasheet 和论文里最常出现的传感器术语压成一个查表页。

QE

量子效率

\(QE=\text{electrons}/\text{photons}\)，需看波长和角度。

BSI

背照式

从硅背面入光，提高小像素 fill factor 和角度响应。

PPD

Pinned photodiode

现代 4T pixel 的核心，支持 CDS、低暗电流和较完整电荷转移。

FWC

满井容量

单像素可容纳最大电子数，影响高光容量和动态范围上限。

Shot

Photon shot noise

\(\sigma=\sqrt{N}\)，信号相关且无法完全消除。

Read

Read noise

读出链路噪声，弱光和动态范围下限的关键。

SNR

信噪比

\(SNR=N_e/\sqrt{N_e+N_d+\sigma_{read}^2+\sigma_q^2}\)。

PTC

Photon Transfer Curve

用均值-方差曲线估算 conversion gain、read noise、FWC 和 PRNU。

CDS

相关双采样

读 reset 和 signal 做差，抵消 reset noise 与部分 FPN。

Rolling

Rolling shutter

逐行曝光/读出，运动时产生 skew、wobble 和闪光半帧。

Global

Global shutter

所有像素同时曝光，但有面积、噪声、满井、PLS 和成本权衡。

DCG

Dual conversion gain

高 gain 保暗部低噪，低 gain 保高光容量，合并得到更宽动态范围。

CFA

Color filter array

Bayer、RGBW、RYYB、多光谱等都在光通量、颜色分离和空间采样间权衡。

SPAD

单光子雪崩二极管

单光子触发数字脉冲，适合 ToF、LiDAR、低光和寿命成像。

Event

事件相机

输出亮度变化事件 \((x,y,t,p)\)，不是完整帧。
