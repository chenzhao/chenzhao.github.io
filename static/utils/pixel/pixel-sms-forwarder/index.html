Pixel SMS Forwarder

Pixel SMS Forwarder is a personal default-SMS application for Android. It receives newly arriving ordinary SMS messages, stores them in Android's system SMS database, and forwards each one as an email using the Gmail API.

The app is designed for personal use on a phone and Google Account controlled by the same user. The user must explicitly select it as the phone's default SMS app; the previous SMS app remains installed but is no longer the default.

What it does

  • Receives new SMS messages after the user grants Android's default SMS role.
  • Shows all SMS messages in Android's system SMS database on the main screen, refreshes the list when the database changes, and provides full-message viewing, copying, replying, sending, and respond-via-message functions.
  • Lets the user explicitly select a Google Account, pins background sending to that account, and uses the minimum OAuth scopes needed to identify it and send email.
  • Sends directly from the phone to the Gmail API; the developer operates no relay server.
  • Encrypts an unsent local queue with an Android Keystore key and deletes each queued record after Gmail confirms delivery.
  • Records local timestamps for the most recent SMS broadcast, system-database write, and successful Gmail send so delivery problems can be diagnosed without logging message content.

What it does not do

  • It does not read the Gmail inbox or contacts. Existing SMS messages can be displayed locally in the app's SMS view, but they are not placed in the email-forwarding queue.
  • It does not download MMS or process RCS conversations.
  • It does not sell data, serve advertising, or use analytics.
