5. 同态 / Homomorphisms

保持运算的翻译 / Translations that preserve operation

同态把一个群翻译到另一个群，同时保留“先组合再翻译”和“先翻译再组合”的一致性。A homomorphism translates one group into another while preserving composition.

展开原理 / Expand

如果一个映射会破坏运算，它只是普通函数；如果它保留运算，它就能把一个群的结构搬到另一个地方。同态让我们比较不同表面的同一种结构。

If a map breaks the operation, it is just a function. If it preserves the operation, it carries group structure from one setting to another and lets us compare different-looking systems.

结构检查 / Structure check
\[f(a*b)=f(a)*f(b)\]

6. 核 / Kernel

哪些动作被翻译成“什么都不做” / Which actions collapse to identity

核记录同态中被压扁到单位元的元素，它告诉我们翻译丢掉了多少信息。The kernel records what the translation forgets.

展开原理 / Expand

当多个元素都被送到单位元，翻译就把这些差别视为不重要。核不仅是一个集合，还是一个子群；它是理解商群和结构压缩的入口。

When several elements map to the identity, the translation treats their differences as irrelevant. The kernel is itself a subgroup and is the gateway to quotients and compression.

信息漏斗 / Information funnel
\[\ker f=\{g\in G:f(g)=e_H\}\]

7. 商群 / Quotient groups

把陪集当成新的元素 / Treat cosets as new elements

商群把一个子群内部的差别折叠掉，只保留陪集之间如何组合。A quotient folds away differences inside a subgroup and keeps how cosets combine.

展开原理 / Expand

陪集已经把群分成整齐层。商群进一步说：把每一层看成一个新元素。这样可以从复杂群中提取一个更粗、更容易理解的结构。

Cosets already partition the group. A quotient takes the next step: each layer becomes a new element, giving a coarser structure that is easier to reason about.

分层压缩 / Layer compression
\[G/H=\{aH:a\in G\}\]

8. 群作用 / Group actions

群通过作用连接到对象 / Groups meet objects through actions

群作用说明一个抽象群如何移动某个集合里的对象，例如旋转正方形的角。A group action explains how abstract elements move objects.

展开原理 / Expand

群不一定直接由几何动作组成，但它可以作用在几何对象、解集、颜色排列或数据状态上。作用把抽象运算变成可以观察的运动。

A group need not be made of geometric motions, but it can act on shapes, solution sets, colorings, or data states. Actions turn abstract composition into observable movement.

作用图 / Action map
\[\alpha:G\times X\to X,\qquad (g,x)\mapsto g\cdot x\]
