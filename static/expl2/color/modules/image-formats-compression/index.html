Learning path

先看 JPEG。再把它推广到其他格式。

JPEG 是最好的入门样本。它的结构短。数学清楚。工程取舍也清楚。 主线如下：像素块先变成 DCT 系数，再量化，再重新排列，再熵编码。

\[ P \xrightarrow{-128} f \xrightarrow{DCT} F \xrightarrow{/Q,\ round} \widehat F \xrightarrow{Zigzag} z \xrightarrow{RLE+Huffman} bits \]

DCT 本身不是有损算法。它只是换坐标。真正丢信息的是量化、色度下采样、舍入和丢弃系数。

像素 8×8 块 DCT 量化 Zigzag / RLE 熵编码

DCT core

DCT 把像素块换成一组余弦基的权重

位置语言

像素矩阵直接记录每个位置的亮度。它直观，但相邻像素常常重复。

频率语言

DCT 记录每种余弦纹理占多少。低频描述大形状。高频描述边缘、纹理和噪声。

正交投影

每个系数来自内积。基函数正交，所以各个系数可以独立解释。

能量集中

自然图像的小块通常平滑。DCT 后，能量常集中在左上角低频系数。

Codec map

格式比较放在 DCT 主线之后

JPEG

DCT 教科书样本

8×8 DCT、量化表、Zigzag、DC 差分、AC 游程、Huffman。结构简单，适合细讲。

PNG

图形与透明的无损答案

行过滤、DEFLATE、调色板、alpha 和 chunk 扩展。适合 UI、截图、二维码，不适合大多数照片分发。

WebP

把视频编码思想带到 Web

lossy 侧来自 VP8 帧内预测，lossless 侧用可逆变换、LZ77、prefix coding 与颜色缓存。

HEIC / HEIF

现代手机照片容器

HEVC intra coding 加 HEIF 容器，可承载主图、缩略图、深度图、HDR 元数据和图像序列。
