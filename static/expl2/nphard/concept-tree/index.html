P、NP 与 P vs NP：概念依赖图

从“可判定”开始，理解高效求解 P，再理解高效验证 NP、证据、归约、NP-hard，最后到 P vs NP。 Start with decidability, then P, NP, certificates, reductions, NP-hardness, and finally P vs NP.

目录 / Directory 单页版 / Single page

可判定 / Decidable

定义计算问题是否存在通用判定算法。A general algorithm halts and answers yes/no for all valid inputs.

\[\forall x,\ A(x)\downarrow\ \text{and decides }x\in L\]
  • 前置 / Upstream: 计算问题 / computational problem
  • 后继 / Downstream: P, NP

P

可判定问题中已知能多项式时间求解的一类。Decision problems known to be solvable in polynomial time.

\[\mathrm{P}=\bigcup_{k\ge1}\mathrm{TIME}(n^k)\]
  • 前置 / Upstream: 可判定 / decidable
  • 后继 / Downstream: P vs NP

NP

“是”的答案有短证据并可多项式时间验证。Yes instances have short certificates checkable in polynomial time.

\[x\in L\iff \exists y,\ |y|\le |x|^c\land V(x,y)=1\]
  • 前置 / Upstream: 可判定 / decidable
  • 后继 / Downstream: 证据, NP-hard, P vs NP

证据 / Certificate

验证器用来快速检查候选答案的短说明。A short witness used by a verifier.

\[V(x,y)=1\]
  • 前置 / Upstream: NP
  • 后继 / Downstream: P vs NP

归约 / Reduction

把一个问题高效翻译成另一个问题。An efficient translation between problems.

\[A\le_p B\iff x\in A\Longleftrightarrow f(x)\in B\]
  • 前置 / Upstream: P, NP
  • 后继 / Downstream: NP-hard

NP-hard

至少和 NP 中所有问题一样难。At least as hard as every problem in NP.

\[\forall L\in\mathrm{NP},\ L\le_p X\]
  • 前置 / Upstream: NP, 归约 / reduction
  • 后继 / Downstream: P vs NP

P vs NP

询问快速验证是否意味着快速求解。Does efficiently checkable imply efficiently solvable?

\[\mathrm{P}\subseteq\mathrm{NP},\qquad \mathrm{P}\stackrel{?}{=}\mathrm{NP}\]
  • 前置 / Upstream: P, NP, 证据, NP-hard
  • 后继 / Downstream: 密码学、优化、自动证明 / cryptography, optimization, automated proof
