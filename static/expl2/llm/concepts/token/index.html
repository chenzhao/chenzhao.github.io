Large Language Models: Tokens, Context, Sampling concept / 概念

Token / token

The basic text unit an LLM processes; a prompt can be written as a token sequence \(x_{1:n}\). 模型处理文本的基本单位；提示词可以写作 token 序列 \(x_{1:n}\)。

Definition / 定义

The basic text unit an LLM processes: a character, word, word piece, number, or punctuation mark.

模型处理文本的基本单位，可能是字、词、词片段、数字或标点。

\[x_{1:n}=(x_1,x_2,\ldots,x_n)\]

Example / 例子

On the main page, this concept is supported by token chips and text input.

主页面用token 标记与文本输入支撑这个概念。

Why it matters / 为什么重要

This concept connects the page's intuition to the later interaction and gives the reader a stable term for review.

这个概念把页面直觉和后续交互连接起来，也给读者一个稳定的复习术语。
