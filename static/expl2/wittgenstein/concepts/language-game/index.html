Concept / 概念

Language-game / 语言游戏

A language-game is a situated linguistic activity with rules, purposes, and criteria. 语言游戏是带有规则、目的和标准的具体语言活动。

Definition / 定义

Later Wittgenstein uses language-games to show that words work differently in reporting, ordering, joking, calculating, and proving.

后期维特根斯坦用语言游戏说明词在报告、命令、玩笑、计算、证明中以不同方式运作。

Example / 例子

"Brick!" is an order at a building site, a sample word in a lesson, and a label in a museum.

“砖！”在工地上是命令，在课堂上是例词，在博物馆里是标签。
