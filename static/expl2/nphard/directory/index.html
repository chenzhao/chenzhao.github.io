概念 / Concepts

  • 可判定 / Decidable: \(\forall x,\ A(x)\downarrow\)
  • P: \(\mathrm{P}=\bigcup_{k\ge1}\mathrm{TIME}(n^k)\)
  • NP: \(\exists y,\ |y|\le |x|^c\land V(x,y)=1\)
  • 证据 / Certificate: \(V(x,y)=1\)
  • 归约 / Reduction: \(A\le_p B\)
  • NP-hard: \(\forall L\in\mathrm{NP}, L\le_p X\)
  • P vs NP: \(\mathrm{P}\stackrel{?}{=}\mathrm{NP}\)
