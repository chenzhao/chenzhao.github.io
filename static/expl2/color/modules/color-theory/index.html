Core question

颜色不是波长，也不是裸 RGB 数字

真实世界给出光谱 \(S(\lambda)\)，人眼和设备把它投影到有限维响应。不同光谱可能产生同一颜色感觉， 同一 RGB 数字在不同 primaries、白点和 transfer function 下也不是同一种颜色。

\[ X=k\int S(\lambda)\bar{x}(\lambda)d\lambda,\quad Y=k\int S(\lambda)\bar{y}(\lambda)d\lambda,\quad Z=k\int S(\lambda)\bar{z}(\lambda)d\lambda \]
光谱LMS/XYZRGB 空间线性/非线性编码Lab/ΔE色彩管理

三刺激与同色异谱

无限维光谱投影到三维视觉响应，解释“看起来一样但光谱不同”。

RGB 不是一个空间

sRGB、Display P3、BT.2020、ACEScg 的 primaries、白点和编码都不同。

线性光是底线

混合、模糊、缩放、alpha 和能量计算应在线性光中做。

管理而不是猜

ICC、ACES/OCIO、3D LUT 和校准让颜色在设备间可审计地流动。
