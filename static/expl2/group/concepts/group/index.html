Group / 群

A set with an operation \((G,*)\) satisfying closure, associativity \((a*b)*c=a*(b*c)\), identity, and inverses. 一个集合加上一种运算 \((G,*)\)，并满足封闭性、结合律 \((a*b)*c=a*(b*c)\)、单位元和逆元四条规则。

Definition / 定义

A set with an operation \((G,*)\) satisfying closure, associativity \((a*b)*c=a*(b*c)\), identity, and inverses.

一个集合加上一种运算 \((G,*)\)，并满足封闭性、结合律 \((a*b)*c=a*(b*c)\)、单位元和逆元四条规则。

\[(a*b)*c=a*(b*c),\qquad e*a=a*e=a\]
